# Changelog

All notable changes to **Masum Galaxy // Future Code** are documented here.

## 3.0.0

- Prepared the extension for Visual Studio Code Marketplace publishing.
- Added a Marketplace-ready PNG icon and gallery metadata.
- Added extension commands for installing, reloading and removing the animated cockpit.
- Removed the hard-coded local cockpit path; the extension now resolves its own installed location.
- Added automatic migration of older Masum Galaxy cockpit import paths.
- Made the Custom CSS and JS Loader optional and installable on demand.
- Improved the Galaxy Cockpit with 8 rotating planet scenes, Sun, Moon, stars, nebula motion, HUD scan effects, active-line treatment and robotic cursor glow.
- Added native-safe menu and popup layering fixes.
- Added Marketplace support, publishing and packaging documentation.

## 2.0.0

- Added the first Galaxy Cockpit prototype.
- Added a 40-second solar-system loop with 5-second planet scenes.
- Added glass-style UI surfaces and the subtle `MASUM BILLAH // GALAXY CORE` signature.

## 1.0.0

- Initial Masum Galaxy color theme.
